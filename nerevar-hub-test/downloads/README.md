# Папка `downloads/`

Сюда складывает файлы **Download Manager** — окно File → Download
Manager и команда `wget <url>` в Terminal. Папка создаётся сама при
первой загрузке, пустой неотличим от отсутствующего.

Что важно:

* **В git не идут** — содержимое игнорируется через `.gitignore`
  (`downloads/*`, исключение только для этого README).
* **Отдаются как вложение.** Файл доступен по прямому адресу
  `/downloads/<имя>` и всегда с заголовком
  `Content-Disposition: attachment`, поэтому скачанная HTML-страница
  сохранится в файл, а не выполнится рядом с панелью. Листинга каталога
  нет — `/downloads/` отдаёт 404.
* **Имя файла** берётся из URL (только последняя часть пути), опасные
  символы заменяются на `_`; повторное имя получает суффикс ` (1)`.
* **Лимит** — `CONFIG.downloads.maxMB` в `config.js` (0 — без лимита);
  превышенное скачивание панель останавливает сама.

Положи сюда файл руками — он тоже будет отдаваться по
`/downloads/<имя>` (с тем же вложением).
