# skins/ — скины для Audio Player

Здесь лежат скины плеера в формате **Qmmp / Winamp 2**.

Файл скина — это `.wsz` (по сути ZIP, внутри него BMP-файлы:
`main.bmp`, `cbuttons.bmp`, `titlebar.bmp`, `pledit.bmp`, …).
Такие скины одинаково работают и в Winamp 2, и в Qmmp, и в этом плеере.

## Куда класть

Положите файл прямо в эту папку — после обновления страницы он появится
в списке скинов в окне Audio Player.

```
nerevar-hub/
├── skins/
│   ├── base.wsz          <- ваш скин
│   └── README.md
├── index.html
└── server.py
```

Ничего перезапускать не нужно: и список (`/api/skins`), и сам файл
(`/skins/<имя>`) отдаются при каждом запросе.

## Откуда брать скины

* <https://qmmp.ylsoftware.com/files/skins/> — коллекция для Qmmp
* <https://skins.webamp.org/> — архив классических скинов Winamp 2
* любой `.wsz`, найденный в интернете

Скин можно и не класть в папку: в окне плеера есть кнопка **«Skin…»**,
она читает `.wsz` прямо с вашего диска — файл никуда не отправляется.
Ещё файл можно просто перетащить на окно плеера.

## Как это устроено

Сервер отдаёт архив как есть, а разбирает его браузер:

1. ZIP читается прямо в странице (ZIP + `DecompressionStream`);
2. каждый BMP превращается в `canvas` (8/24/32 bpp, без сжатия);
3. окно рисуется на `<canvas>` по координатам Winamp 2 — они одинаковы
   у всех скинов, потому что их задаёт формат, а не конкретный автор.

Цвета текста плейлиста берутся из `pledit.txt` внутри архива
(`Normal`, `Current`, `NormalBG`, `SelectedBG`, `Font`); если файла нет —
действуют классические значения Winamp.

## Настройка в index.html

Смотрите `CONFIG.music.skins`:

| ключ              | что делает                                        |
|-------------------|---------------------------------------------------|
| `enabled`         | `false` — убрать панель выбора скина целиком       |
| `dir`             | URL-префикс папки (по умолчанию `skins/`)          |
| `list`            | endpoint со списком, `''` — список не запрашивать  |
| `start`           | имя скина, который включается при загрузке страницы|
| `scale`           | во сколько раз увеличено окно Winamp (по умолчанию 2) |
| `playlistHeight`  | высота окна плейлиста в пикселях скина             |

## Ограничения

* Разрешены только расширения `.wsz` и `.zip`.
* Выход за пределы папки (`../`, абсолютный путь, симлинк наружу)
  получает 404 — как и в `pics/`.
* Нужен браузер с `DecompressionStream` (Chrome 80+, Firefox 113+,
  Safari 16.4+): только он умеет распаковывать сжатые архивы в JS.
