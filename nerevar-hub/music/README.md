# music/ — треки для Audio Player

Здесь лежат файлы, которые играет окно **Audio Player**. Сервер отдаёт их
по `GET /music/<имя>` (перемотка работает через `Range`), а список треков
панель берёт из `GET /api/music`.

## В репозиторий не кладётся

`music/*` целиком в `.gitignore`: свои треки и чужая музыка в git не
попадают — остаются локально. В git идёт только этот `README.md`.

Поэтому на GitHub папка выглядит пустой, а плеер на новом компьютере
покажет `No track` — так и задумано. Чтобы музыка появилась:

* просто скопируйте файлы в `music/` на сервере; или
* положите диск в другое место и укажите его серверу:

```bash
python3 server.py --music-dir /mnt/hdd/music
```

## Куда класть

Поддерживаются расширения `.mp3` `.m4a` `.aac` `.ogg` `.oga` `.opus`
`.wav` `.flac` `.weba` `.webm` — всё, что умеет декодировать ваш браузер.
Читаются только файлы верхнего уровня, скрытые (`.` в начале имени)
пропускаются.

```
nerevar-hub/
├── music/
│   ├── 01 - track.mp3     <- ваш трек
│   ├── 02 - track.flac
│   └── README.md
├── index.html
└── server.py
```

Ничего перезапускать не нужно: и список (`/api/music`), и сам файл
(`/music/<имя>`) отдаются при каждом запросе.

## Если трек не играет

Браузер декодирует файл сам, поэтому список форматов зависит от
браузера. Файл с «unsupported or damaged audio file» браузер считает
битым — например, некоторые FLAC с испорченной обложкой отвергает
Chromium; лечится так:

```bash
metaflac --remove --block-type=PICTURE "имя трека.flac"
```

## Настройка в config.js

Смотрите `CONFIG.music`:

| ключ        | что делает                                              |
|-------------|---------------------------------------------------------|
| `enabled`   | `false` — убрать окно и кнопку в таскбаре целиком       |
| `base`      | URL-префикс папки (по умолчанию `music/`)               |
| `list`      | endpoint со списком, `''` — список не запрашивать       |
| `tracks`    | ручной список треков вместо endpoint                    |
| `startOpen` | открывать окно сразу при загрузке страницы              |
| `volume`    | громкость 0..1                                          |
| `loop`      | `'off'` \| `'all'` \| `'one'` (кнопка R)                |
| `shuffle`   | перемешивание (кнопка S)                                 |

`base` может быть и внешним адресом, тогда файлы грузятся не с этого
сервера: `base:'https://example.com/music/'`.
