# Папка `pics/`

Единственное место, где лежит содержимое окна **Picture Viewer**: и
картинки, и ascii-арт. Сам `index.html` хранит только имена файлов
(`CONFIG.artFile`, `CONFIG.picFile`) — чтобы поменять арт или
картинку, в страницу лезть не нужно.

## Что сюда класть

| файл | что это |
|---|---|
| `ASCII_ART.TXT` | ascii-арт (обычный текст, имя задаётся в `CONFIG.artFile`) |
| `*.png` `*.jpg` `*.gif` `*.webp` `*.svg` … | картинки, открываются вручную или через `CONFIG.picFile` |
| `README.md` | этот файл — сервер его отдавать не будет (404) |

Адрес у всех: `http://<сервер>/pics/имя-файла`.

Открыть картинку в панели: **File → Open image…** → вписать
`/pics/имя-файла.gif` → **Open**, либо просто перетащить файл на окно
Picture Viewer.

## Что показывать при загрузке

В `CONFIG` (в `index.html`):

```js
artFile:'ASCII_ART.TXT', // ascii-арт из этой папки ('' — не грузить)
picFile:'',              // '' — ascii-арт;
                         // 'cat.png' — конкретная картинка;
                         // '~.png' / '~.gif' / '~' — случайная
```

`~.png` — при каждой загрузке страницы панель запрашивает `/api/pics`,
получает список имён и выбирает наугад одно подходящего расширения.
Новая картинка в папке начинает выпадать сразу после обновления вкладки.

## Какие файлы отдаются

| расширение | тип |
|---|---|
| `.png` `.jpg` `.jpeg` `.gif` `.webp` `.apng` `.avif` `.bmp` `.ico` | картинка |
| `.svg` | картинка, но скрипты внутри запрещены (CSP) |
| `.txt` | ascii-арт (`text/plain`) |

Всё остальное (`.html`, `.js`, `.md`, …) — 404.

## Ограничения безопасности

* Отдаются **только** файлы внутри `pics/`: попытки выйти за её пределы
  (`../`, абсолютный путь, симлинк наружу) дают 404.
* Каталоги и несуществующие файлы — 404, списка содержимого по HTTP нет
  (есть JSON-список `/api/pics` — только имена файлов, ничего больше).
* Заголовки: `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`,
  для небезопасных типов — `Content-Security-Policy: default-src 'none'`.
* Метод `HEAD` поддерживается (удобно для проверок доступности).

Если папки нет — `server.py` работает как раньше, а `/pics/` и
`/api/pics` отдают 404 и пустой список.
