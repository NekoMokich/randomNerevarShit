
  ============================================================================
  SERVER HUB — Win9x-style dashboard for a personal home server
  ============================================================================

  БЫСТРЫЙ СТАРТ
  -------------
  Это один самодостаточный HTML-файл. Просто открой его в браузере.
  Для публикации: скопируй файл в корень репозитория как `index.html`.
  Полностью на вайбкодженно

  ---------------------------------------------------------------------------
  ЧТО МЕНЯТЬ ПОД СВОЙ СЕРВЕР
  ---------------------------------------------------------------------------
  Всё настраивается в одном месте — объект CONFIG в самом низу файла,
  в начале скрипта (ищите `const CONFIG = {`).

    1. serverName       — имя твоего сервера. Показывается в заголовке вкладки,
                          в заголовке окна, в таскбаре и в окне Help.
                          Пример: 'My Home Server'

    2. serverIcon       — одна буква для иконки в заголовке окна.
                          Пример: 'S'

    3. welcomeTitle     — заголовок приветствия.
    4. welcomeText      — текст приветствия (краткое описание сервера).

    5. lanHost          — адрес в локальной сети, который будет подставлен
                          в ссылки сервисов. Пример: '192.168.1.10'
    6. tailscaleHost    — имя узла в Tailscale или его MagicDNS-адрес.
                          Пример: 'myserver' или '100.64.0.1'

    7. favoriteUrl      — ссылка, которая открывается по кнопке «Favorites».
                          Пример: 'https://example.com'

    8. services         — массив сервисов. Каждый элемент:
                            {
                              name:  'Название сервиса',   // обязательно
                              port:  '8080',               // обязательно
                              note:  'описание',           // необязательно
                              icon:  '🌐'                  // необязательно
                            }
                          icon — любой символ/эмодзи, который покажется
                          на иконке карточки (📁 🌐 🎬 🗳 …).
                          Если icon не задан или пустой, ставится номер по счёту.
                          Добавляй/удаляй элементы массива — карточки в списке
                          и счётчик в статус-баре обновятся автоматически.

    9. help             — содержимое окна Help. Поддерживает HTML-теги:
                            help: {
                              windowTitle:'Help',        // заголовок окна
                              title:     'Help',        // крупный заголовок
                              intro:     'Текст-вступление.',
                              items:     [ 'Пункт списка 1', 'Пункт списка 2' ],
                              html:      '<p>Любой свой HTML</p>'  // необязательно
                            }
                          items — массив строк; каждая станет <li> списка.
                          intro, items и html поддерживают теги: <b>, <i>, <code>,
                          <a>, <br>, <img> и т.д. Если поле не указано — оно пропускается.

    10. artWindowTitle  — название окна с ASCII-артом (пишется в таскбаре).
                          Пример: 'Picture Viewer'
    11. artFileName    — «имя файла» в заголовке этого окна. Изначально ASCII_ART.TXT,
                          но можно написать что угодно: 'cat.txt', 'logo.anime',
                          'Мой арт' и т.д.
                          Пример: 'my_art.txt'
    12. artIcon        — буква/эмодзи для иконки этого окна. Пример: 'P'

    13. numberStyle    — как выглядит ЦИФРА в иконке сервиса, которому не задан
                          icon (номер по счёту):
                            'title' — как название сервиса (14px, жирный, синий)
                            'big'   — крупная цифра 19px
                          По умолчанию 'title'.

  ---------------------------------------------------------------------------
  ЧТО МЕНЯТЬ НЕ НУЖНО
  ---------------------------------------------------------------------------
  • ASCII-арт — лежит в pre в окне Picture Viewer (строки с символами ⠀).
    Он сам подстраивается под размер окна.
  • Окна можно двигать за заголовок и менять размер за угол окна (справа снизу).
  • Текст справки берётся из CONFIG.help (см. пункт 9 выше).

  ---------------------------------------------------------------------------
  ПОДСКАЗКИ
  ---------------------------------------------------------------------------
  • Адреса можно менять прямо в интерфейсе — поля сверху. Ссылки пересобираются
    сами, но значения из CONFIG используются как значения по умолчанию.
  • Пункт меню «View -> Zoom» масштабирует ASCII-арт.
  • Надпись «N services» в статус-баре считается автоматически.
